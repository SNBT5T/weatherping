# 🌦️ WeatherPing – DevOps Beadandó Projekt

A WeatherPing egy egyszerű Node.js alapú időjárás-ping API, amelyen keresztül bemutathatók a DevOps alaplépései: kódkészítés, build, verziókezelés, Docker, CI, DevContainer, IaC és felhő deploy.

---

# Projekt célja

A beadandó célja egy egyszerű HTTP-n elérhető alkalmazás létrehozása, majd a teljes DevOps workflow bemutatása:

- ✔ alkalmazásfejlesztés
- ✔ trunk-based git használat
- ✔ buildelés
- ✔ Docker image készítése és futtatása
- ✔ CI pipeline
- ✔ DevContainer alapú fejlesztőkörnyezet
- ✔ Terraform IaC
- ✔ felhő deploy (Render)
